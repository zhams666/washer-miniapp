# CloudBase PostgreSQL Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the existing Spring Boot API against the free CloudBase PostgreSQL environment without changing its HTTP API.

**Architecture:** Keep the default local profile on MySQL so existing local development remains usable. The `cloudbase` profile overrides only the datasource to PostgreSQL; a PostgreSQL-specific fresh-install schema is added beside the existing MySQL migrations and includes update triggers for `updated_at` columns.

**Tech Stack:** Spring Boot 3.2, MyBatis-Plus, PostgreSQL JDBC, SQL migration scripts, Maven.

## Global Constraints

- Preserve the current MySQL migrations and default local database behavior.
- Use PostgreSQL only when `SPRING_PROFILES_ACTIVE=cloudbase`.
- Do not add or commit database credentials, Mini Program secrets, or CloudBase connection strings.
- Keep existing REST paths and request/response contracts unchanged.

```xml

  <groupId>org.postgresql</groupId>
```

```yaml

    password: ${WASHER_PG_PASSWORD}
```

Expected: `BUILD SUCCESS`.

### Task 2: Provide a PostgreSQL fresh-install schema

**Files:**
- Create: `sql/postgresql/001_cloudbase_init.sql`
- Create: `sql/postgresql/README.md`

**Interfaces:**
- Consumes: the final schema represented by `sql/migrations/001.sql` through `014_point_redemption_order.sql`.
- Produces: one idempotent PostgreSQL schema script that creates tables, indexes, seed data, and `updated_at` triggers.

- [ ] **Step 1: Convert MySQL column and constraint semantics**

```sql
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
```

- [ ] **Step 2: Create indexes separately from table definitions**

```sql
CREATE INDEX IF NOT EXISTS idx_device_status ON device (device_status);
```

- [ ] **Step 3: Add an update timestamp trigger for every table with `updated_at`**

```sql
CREATE OR REPLACE FUNCTION set_updated_at() RETURNS trigger AS $$
BEGIN
  NEW.updated_at = CURRENT_TIMESTAMP;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

- [ ] **Step 4: Add schema application instructions without credentials**

```text
Run sql/postgresql/001_cloudbase_init.sql once in the CloudBase PostgreSQL SQL console.
```
